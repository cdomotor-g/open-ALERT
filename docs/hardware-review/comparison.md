# Hardware review: the comparison tables

The same figures as the [Other computers page](../../site/hardware.html), written out for reading on
GitHub. The page is where to sort, filter and tick computers side by side; these tables are
for reading, printing and quoting. Every row names the research report it rests on (the
reports are in [`research/`](research/)). The review itself, and why it recommends what it
does, is in the [README](README.md).

**Read this first.**

- **Speed is "times a Raspberry Pi 4"**, with the Pi 4 counted as 1. Two figures: the whole
  computer, then one core. Each radio channel is decoded on one core, so both matter. Every
  figure is a **stand-in**: a number borrowed from published benchmarks of other software on
  the same kind of processor. No benchmark runs this decoder, and nobody has yet run the
  benchmark in [`firmware/bench`](../../firmware/bench/) on any of these computers
  ([U2](research/U2-decoder-cost-and-bench.md), [R8](research/R8-cpu-performance.md)).
- **The ALERT2 rule** for buying with room to grow: at least four cores, each at least 2.5
  times a Raspberry Pi 4 core ([U2](research/U2-decoder-cost-and-bench.md),
  [R9](research/R9-alert2-demands.md)). Four channels need about 2.5 Pi 4s in all; eight
  channels about 4. "Meets it at the planning figure" means at the figure the review plans
  with: an N150 is planned at about 3 a core, and the lowest published benchmark puts it at
  about 2.4, just under the rule.
- **Prices are Australian dollars including GST where known.** Where a price could not be read
  the table says "check with the seller" and gives the seller's link. Overseas prices are
  converted at this site's planning rates, US$0.69 and EUR 0.63 to the dollar. The owner will
  check prices by hand in a browser: **the links matter more than the figures.** Several shops
  (Core Electronics, PB Tech, element14, Arrow) refuse automated reading, so their figures come
  from search listings or are missing. Some sellers' pages were opened again on 13 November
  2026; the rows say which.
- A blank or "not read" means the review did not find it out. It is not a "no".
- Terms: *TPM* is a small chip that keeps secret keys where software cannot copy them.
  *Secure boot* means the computer refuses to start software nobody it trusts has signed.
  *Fanless* means cooled through the case with no fan to wear out. *Open hardware* means the
  board's design files are published under a licence that lets anyone study, change and make
  it. *Package* is the one-file installer, `open-alert-base`, for Debian 13 and Ubuntu 24.04.
  The full list of meanings is on the Other computers page.

The computers are in the review's groups, first choice first. The four tables have the same
rows in the same order.

## How to use these tables

1. Start from the group, not the price: a first-choice computer is there for a reason.
2. Check the speed against the number of channels using the builder
   (<https://cdomotor-g.github.io/open-ALERT/build.html>), not by eye.
3. Open the seller's link and read the price in a browser. Update the record in
   `site/data/review.js` (and the catalogue, `site/data/compute.js`) when you find it differs,
   and run `npm test`. This file is written from `review.js`; bring it into line by hand.
